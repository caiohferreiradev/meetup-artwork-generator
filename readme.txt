Standardized artwork and announcement texts for WordPress community meetups, ready for Meetup.com, Facebook, Instagram, LinkedIn, X and WhatsApp.

== Description ==

Meetup Artwork Generator turns a WordPress site into a simple tool for meetup organizers. On activation, the generator becomes the site front page. Organizers fill in a guided form and download the artwork for each network, with no login and no design skills needed.

* Community city (searchable, any city works), with the silhouette of a local landmark in the background, or your own image as a watermark.
* Event type (in person or online), edition number, date, time and time zone, meetup title (theme) and description.
* Venue, optionally shown on the artwork.
* Talks with title, speaker name and photo, as many as you need.
* Supporter and sponsor logos.
* Light or dark artwork.
* Formats: Meetup.com (1920×1080), Facebook event cover (1920×1005), link post (1200×630), X (1600×900), square (1080×1080), portrait (1080×1350) and Status/Stories (1080×1920).

After downloading, the optional "Announcement texts" section offers a ready-made text for each network, filled with the form details and with a copy button. Each text follows its network: a hook on the first line, scannable essentials, one clear call to action, CamelCase hashtags, "link in bio" on Instagram, WhatsApp bold and the 280-character limit on X. Missing details show up [in brackets].

The generator speaks Portuguese, English and Spanish. It follows the visitor's browser language and can be switched at the top of the page; the choice is kept in a cookie.

Everything happens in the browser: no image or text is sent to any server. What you fill in is saved in your own browser until you click "Start over".

The Inter and IBM Plex Mono fonts ship with the plugin (SIL Open Font License 1.1), so it also works offline.

The landmark list covers Brazilian WordPress communities. Any city can be typed in, and new cities, landmarks, formats and languages can be added with filters or contributions.

== Installation ==

= WordPress Playground =

No installation needed, it runs in the browser:

`https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/caiohferreiradev/meetup-artwork-generator/main/playground/blueprint.json`

To run it on your own computer without depending on GitHub, build the bundle with `tools/build-playground-bundle.sh` and run:

`npx @wp-playground/cli server --blueprint=dist/meetup-artwork-generator-playground.zip`

= Any WordPress site =

1. Upload the `meetup-artwork-generator` folder to `wp-content/plugins/`, or upload the zip in Plugins → Add New → Upload Plugin.
2. Activate the plugin. It creates the "Meetup Artwork Generator" page and sets it as the front page.
3. On deactivation, the previous front page is restored. The generator page itself is kept.

To show the generator on another page, add the `[meetup_artwork_generator]` shortcode.

== Frequently Asked Questions ==

= My city is not in the list =

Type its name in the City field. To add it to the list, add the city to `includes/cities.php` and open a pull request.

= How do I add a landmark? =

1. Draw a single-color (black) SVG with the ground on the bottom edge and save it as `assets/landmarks/{id}.svg`. Include `width`, `height` and `viewBox` on the `<svg>`.
2. Register the `id` and name in `wpbr_artes_get_landmarks()` (`includes/cities.php`).
3. Use the `id` in the city's `landmark` field.

The generator paints the drawing in WordPress blue with a gradient, creating the shadow effect.

= Can I extend it without editing the plugin? =

Yes, with the `wpbr_artes_cities`, `wpbr_artes_landmarks`, `wpbr_artes_formats`, `wpbr_artes_languages` and `wpbr_artes_default_language` filters.

= How do I update or add translations? =

Source strings are in English. Translations live in `languages/*.l10n.php` (WordPress 6.5+ format) and are generated by `tools/translations.py`, which also reports missing strings: `python3 tools/translations.py .` Translators can start from `languages/meetup-artwork-generator.pot`.
